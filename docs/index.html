S-M-F Terminal est une démonstration. Seuls les actifs marqués d'un point (crypto, forex, actions US avec clé) viennent de sources publiques. Tout le reste (indices, matières, taux, calendrier, actualités, CESI, taux implicites, COT) est simulé. Ne pas utiliser pour prendre des décisions d'investissement.
